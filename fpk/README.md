# MeNote

MeNote，一个轻量级个人笔记知识库系统，支持 Markdown 笔记、分类管理、双向链接、知识图谱。内置 P2P 隧道，手机 App 无需公网 IP 即可直连 NAS 上的笔记服务。数据本地存储，隐私自主可控。

## 功能特性

- 📝 **Markdown 笔记**：Vditor 可视化编辑器，写作体验友好
- 🌳 **分类管理**：树形分类，emoji 图标，拖拽排序
- 🔗 **双向链接**：`[[标题]]` 语法自动解析，反向链接面板
- 🕸️ **知识图谱**：笔记关系可视化（vis-network）
- 🔐 **数据隐私**：SQLite 本地存储，数据完全自主可控
- 📱 **P2P 直连**：内置 iroh 隧道（relay+打洞），手机 App 在外网也能连回家里的 NAS，无需公网 IP
- 🌐 **多端编辑防冲突**：乐观锁机制，多处同时编辑不会互相覆盖

## 端口说明

| 端口 | 用途 |
|------|------|
| 3107 | Web 界面、管理后台、API（安装时可通过向导修改对外端口） |

注：P2P 隧道走 iroh relay + NAT 打洞，出站连接，无需开放额外入站端口。

## 安装方法

1. 将 `menote.fpk` 文件传输到飞牛 fnOS 设备
2. 打开飞牛应用中心
3. 选择"本地安装"
4. 选择该 `.fpk` 文件进行安装
5. 等待安装完成，应用将自动启动

## 首次使用

1. 访问 `http://飞牛IP:端口`（默认 3107）
2. 首次访问会自动进入安装向导，设置管理员账号和密码
3. 进入管理后台（`/admin`）开始创建笔记

## 手机 P2P 直连（可选）

1. 在管理后台"P2P 管理"页面查看服务器节点 ID（或扫码）
2. 手机安装 MeNote Android 客户端，填入/扫码录入节点 ID
3. 首次连接在管理后台授权一次，之后长期有效
4. 手机 App 直接访问 NAS 上的 MeNote，全程加密

> 容器重建不会更换节点 ID（密钥在数据卷中），手机端无需重新配对。

## 数据存储位置

应用数据保存在共享目录 `menote/` 下（文件管理器可见）：

- `menote/data/` - SQLite 数据库、P2P 节点密钥、配对白名单
- `menote/upload/` - 笔记中上传的附件

## 常见问题

### 1. 应用无法启动

检查 Docker 是否正常运行，以及镜像是否成功拉取。可以在飞牛的 Docker 管理界面查看容器日志。

### 2. 无法访问 Web 界面

- 确认应用已启动（在应用中心查看运行状态）
- 检查安装时设置的端口是否被其他应用占用
- 尝试访问 `http://飞牛IP:端口`

### 3. 如何备份数据

将共享目录 `menote/` 整体备份即可（含数据库、密钥、附件）。

### 4. 如何更新应用

在应用中心下载新版本的 `.fpk` 文件，重新安装即可。数据在共享目录中，自动保留。

## 打包与安装

1. 应用图标已就绪（根目录 `ICON.PNG` 64px、`ICON_256.PNG` 256px，入口图标 `app/ui/images/icon_{0}.png`）
2. 安装 [fnpack](https://developer.fnnas.com/docs/cli/fnpack/) 工具
3. 在 `fpk/` 目录执行 `fnpack build` 生成 `menote.fpk`
4. 将 `.fpk` 文件安装到飞牛 fnOS 设备
